## 字符串解码（已完全破解）

```lua
-- 格式：E 前缀 + base-85 编码
function decode(str):
    q = str[2:]                        -- 去掉 E
    for each 5-char block:
        D = 0
        for k in 0..4: D = D*85 + X[char]     (不足补 84)
        b1 = floor(D / 2^24) % 256
        b2 = floor(D / 2^16) % 256
        b3 = floor(D / 2^8) % 256
        b4 = D % 256
        emit 1~4 bytes (按块内字符数决定)
```

## 陷阱记录

1. **`P(29157)` 解出乱码是正常的** —— 它是 `unpack or table[P(29157)]` 里的故意无效 fallback
2. **base 是 85 不是 64** —— 按 base64 解会得到看似合理但完全错误的字节
3. **X 表 85 项**（0-84），漏一项就会解码失败
4. **字符表里 `["'"]` 要正确处理转义**（源码里是 `["\'"]`）
